# Цикл 2 — агент 3: доступность и interaction design

**Специалист:** Алина, Accessibility / Interaction Design  
**Фокус цикла:** WCAG-паттерны для диалогов, табов и toggle-групп

## Аудит после первого цикла

Первый цикл исправил доступ к досье и семантику шкал, но оставил несколько системных разрывов:

- настройки переводили фокус внутрь, но не удерживали его;
- lore-панели не имели `role="dialog"` и `aria-modal="true"`;
- reset не возвращал фокус;
- debug modal не закрывался по backdrop и `Escape`;
- табы настроек не имели `tablist / tab / tabpanel`;
- выбранные option buttons обозначались классом и галочкой, но не `aria-pressed`;
- динамическая иллюстрация не имела диалоговой семантики;
- несколько обработчиков `Escape` могли закрыть больше одного слоя.

## Реализованный паттерн диалога

Для каждого overlay:

1. Запоминается `document.activeElement`.
2. Overlay добавляется в стек.
3. Фон блокируется классом `dialog-open`.
4. Фокус переводится на предсказуемый элемент.
5. `Tab` и `Shift+Tab` циклически удерживаются в верхнем слое.
6. `Escape` обрабатывает только верхний слой.
7. После закрытия фокус возвращается на источник.

Мобильное досье динамически получает `role="dialog"` и `aria-modal="true"` только на компактной ширине. На desktop оно остаётся обычным sidebar, что важнее, чем постоянная неверная роль.

## Табы

Настройки и инспектор промпта получили:

- `role="tablist"`;
- `role="tab"`;
- `aria-selected`;
- `aria-controls`;
- roving `tabindex`;
- навигацию стрелками, `Home` и `End`;
- связанный `tabpanel`.

## Toggle-группы

Выбор пола, типа места, темпа, сложности, объёма текста, провайдера и модели синхронизирует визуальный класс с `aria-pressed`.

## Безопасное подтверждение

При открытии сброса фокус попадает на «Оставить историю», а не на необратимое действие. Это уменьшает риск случайного подтверждения клавишей Enter.

## Остаток на следующий цикл

- добавить screen-reader smoke test для динамически отрисованных характеристик;
- отказаться от inline-стилей служебных debug-панелей при будущем рефакторинге.
