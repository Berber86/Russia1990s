# Цикл 2 — агент 4: frontend design engineer

**Специалист:** Сергей, Frontend Architecture / Design Systems  
**Фокус цикла:** единая инфраструктура overlay без зависимостей

## Техническое решение

Вместо отдельных исправлений для каждой модали добавлен общий слой:

- `openOverlay(root, preferredFocus)`;
- `closeOverlay(root)`;
- `releaseOverlay(root)` для анимируемых динамических окон;
- `openOverlayStack`;
- `overlayReturnFocus` на базе `WeakMap`;
- `setupDialogFocusManagement()`;
- `syncBodyInteractionLock()`.

Стек решает вложенные сценарии: например, подтверждение сброса поверх мобильного досье или служебный диалог поверх другого слоя. Возврат фокуса и scroll lock больше не зависят от случайных inline-присваиваний `body.style.overflow`.

## Обновлённые поверхности

- настройки;
- подтверждение сброса;
- альбом близких людей;
- сундук вещей;
- системный лог;
- инспектор промпта;
- динамическая модаль иллюстрации;
- мобильное досье как fallback-диалог для focus trap.

## Семантические состояния

`setToggleSelected()` атомарно обновляет класс `selected` и `aria-pressed`. Это предотвращает расхождение визуального и доступного состояния.

Для табов используются отдельные функции активации. Они синхронизируют:

- класс;
- `aria-selected`;
- `tabIndex`;
- видимость panel;
- `aria-labelledby` динамического содержимого.

## Регрессионный контракт

Добавлен zero-dependency тест:

```bash
node tests/ui-contract.test.mjs
```

Он проверяет:

- уникальность HTML ID;
- наличие диалоговой семантики;
- структуру tablist/tab/tabpanel;
- polite live-region;
- отсутствие `alert()`;
- наличие общей overlay-инфраструктуры;
- ARIA-синхронизацию toggle и tabs;
- scroll lock и правильный слой подтверждения.

## Риски

Проект остаётся большим монолитным ES-модулем. Общий overlay manager уменьшает дублирование, но следующим архитектурным шагом должно быть выделение UI primitives в отдельный модуль только после появления browser-based integration tests.

## Итог

Цикл не добавил зависимостей, не изменил формат `localStorage` и не затронул LLM/API-логику. Изменения сосредоточены в инфраструктуре взаимодействия.
