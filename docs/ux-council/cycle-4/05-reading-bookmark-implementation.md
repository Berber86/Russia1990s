# Цикл 4 — реализация: добровольная закладка чтения

**Основание:** исследовательская задача совета после режимов чтения.  
**Граница:** локальная помощь при чтении текущей записи; без влияния на игру и без автоматического перемещения страницы.

## Принятый паттерн

Позиция чтения сохраняется только во время чтения **текущей** записи. При следующем открытии соответствующего хода интерфейс показывает компактную карточку «Личная закладка / Продолжить чтение». Никакой автопрокрутки при загрузке, рендере или переходе в игру нет: переход выполняется только после явного нажатия читателя.

## Техническое поведение

- ключ локального хранилища: `rpg90_reading_bookmark`;
- значение содержит номер текущего хода и примерную относительную позицию на странице;
- прогресс не сохраняется в начале и в самом конце записи, чтобы не создавать бесполезную «закладку»;
- архивные записи намеренно не получают закладок: архив остаётся режимом свободного исследования;
- если текст записи менялся или геометрия страницы отличается, позиция трактуется как приблизительная; интерфейс не обещает возврат к конкретной строке;
- данные героя и `state` не меняются.

## Доступность и поток

- карточка — обычная видимая кнопка с ясным действием;
- фокус не перемещается сам;
- действие использует плавную прокрутку только после пользовательского клика;
- после перехода показывается короткое ненавязчивое toast-подтверждение.

## Ограничение

Закладка привязана к номеру хода, а не к отдельным абзацам. Это осознанный компромисс: разметка генерируемой прозы не получает искусственных идентификаторов, а интерфейс не выдаёт приблизительное место за точную строку.
