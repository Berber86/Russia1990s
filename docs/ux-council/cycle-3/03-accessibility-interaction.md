# Цикл 3 — агент 3: accessibility и interaction design

**Специалист:** Алина, Accessibility / Interaction Design  
**Фокус:** привлекательность без зависимости от цвета

## Риски графического подхода

Сегментированная диаграмма может стать декоративной и непонятной, если состояние передаётся только цветом. Поэтому графический preview дополнен текстовыми каналами.

## Каналы информации

### На кнопке

- «Открыть досье» описывает действие;
- «Состояние героя» называет объект;
- динамическая строка сообщает количество отклонений;
- `aria-label` получает итоговую оценку и количество отклонений;
- стрелка подтверждает, что это переход, а не индикатор без действия.

### Внутри досье

- заголовок состояния: от «Полный баланс» до «Критическая грань»;
- предложение с названиями характеристик, дальше всего ушедших от 5;
- отдельное количество зон риска;
- напоминание «центр шкалы — 5»;
- детальные числовые карточки остаются ниже.

## Доступность на мобильном

Кнопка фиксируется у нижнего края, поскольку игрок принимает решение после длинной главы. Справа оставлено место для переключателя темы. При открытом drawer или dialog кнопка скрывается и исключается из взаимодействия.

## Движение

Пульсация применяется только для критического состояния. Глобальное правило `prefers-reduced-motion` проекта отключает эту анимацию. Обычные hover-переходы не являются единственным способом обнаружить контрол.

## Семантика графики

Оба кольца помечены `aria-hidden="true"`: screen reader получает более точную текстовую сводку, а не восемь безымянных декоративных секторов. Детальные значения доступны через существующие `role="meter"`.

## Итог

Контрол стал заметнее для зрячего пользователя, но сохранил полноценное текстовое объяснение и доступность с клавиатуры и screen reader.
