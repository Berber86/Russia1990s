# Цикл 3 — агент 4: frontend graphics engineer

**Специалист:** Сергей, Frontend / Data Visualization  
**Фокус:** графика из живого состояния без новых зависимостей

## Реализация кольца

Графика строится CSS `conic-gradient`, вычисленным из `state.stats`:

```text
8 характеристик × сектор 45°
цвет сектора = abs(value - 5)
между секторами = прозрачный зазор
```

Основные функции:

- `getStatusRingColor(value)`;
- `buildStatusRingGradient(stats)`;
- `renderStatusGraphic()`;
- `pluralizeRu()` для корректных динамических подписей.

Один gradient передаётся через CSS custom property `--status-ring` в мини-кольцо и крупное кольцо досье. Canvas, SVG path calculations и внешние библиотеки не нужны.

## Динамические данные

При каждом `renderUI()` обновляются:

- цвета восьми секторов;
- пиктограмма пола героя;
- тон кнопки;
- доступное название кнопки;
- число отклонений;
- заголовок сводки;
- две характеристики с максимальным отклонением;
- число зон риска.

## Графические ресурсы

Новые тяжёлые изображения не добавлялись. Сезонное окно использует уже оптимизированные файлы `city_*` и `village_*` для четырёх сезонов. Это сохраняет бюджет загрузки, а ресурсы уже кэшируются текущим интерфейсом.

## Responsive

- desktop: полное досье постоянно видно, trigger скрыт;
- tablet до 1080 px: trigger-карточка находится в masthead;
- mobile до 700 px: trigger фиксирован снизу с резервом под theme toggle;
- до 360 px: скрывается второстепенная подпись и стрелка.

## Регрессии

`tests/ui-contract.test.mjs` расширен проверками понятного текста кнопки, графического preview, сводки досье, генерации кольца из `state.stats` и постоянной доступности mobile trigger.
